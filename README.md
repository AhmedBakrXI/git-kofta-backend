## Getting Started

### Prerequisites

* pip
  ```sh
  pip install -r requirements.txt
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/AhmedBakrXI/git-kofta-backend.git

   cd git-kofta-backend
   ```

2. Create a Virtual Environment
   ```sh
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Install packages
   ```sh
   pip install -r requirements.txt
   ```

4. Enter your Backend url in `.env`
   ```js
   GITHUB_CLIENT_ID = 'ENTER YOUR GITHUB CLIENT ID'
   GITHUB_CLIENT_SECRET = 'ENTER YOUR GITHUB CLIENT SECRET'
   FRONTEND_URL = 'ENTER YOUR FRONTEND URL'
   ```
5. Run the project
   ```sh
   fastapi dev
   ```
